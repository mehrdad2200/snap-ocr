**Snap OCR** یک برنامه‌ی کوچک ویندوزی است که همیشه در سینی (کنار ساعت) فعال می‌ماند. یک میانبر می‌زنی، با موس روی هر چیزی در صفحه (عکس، ویدیو، PDF، اسکن، بازی، ریموت دسکتاپ و…) یک مستطیل می‌کشی و متنش در کلیپ‌بورد کپی می‌شود. برنامه کاملاً **آفلاین** روی [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) کار می‌کند و زبان را **خودکار تشخیص می‌دهد**، از جمله زبان‌های **راست‌به‌چپ مثل فارسی و عربی**.

## ویژگی‌ها

- **میانبر سراسری دلخواه**: هر ترکیبی (مثلاً `Ctrl+Alt+O`، `F8` یا `Ctrl+Shift+Space`) که از منوی آیکون تنظیم می‌کنی.
- **دو حالت**: *حالت پنجره* نتیجه را در یک پنجره‌ی تیره و مینیمال نشان می‌دهد؛ *حالت سریع* فقط متن را کپی می‌کند و یک اعلان کوچک می‌دهد.
- **تشخیص خودکار زبان**: اول فارسی، عربی و انگلیسی با یک بار اجرا امتحان می‌شوند. اگر اطمینان کم بود، خط‌های دیگر (سیریلیک، چینی، ژاپنی، کره‌ای، یونانی، عبری، هندی، تایلندی) و زبان‌های لاتین (ترکی، فرانسوی، آلمانی، اسپانیایی و…) هم‌زمان بررسی می‌شوند. هر زبانی که داده‌ی Tesseract آن نصب باشد پشتیبانی می‌شود.
- **انتخاب دستی زبان** با دکمه‌های کوچک، وقتی خودت می‌دانی چه زبانی است.
- **نمایش راست‌به‌چپ** خودکار برای متن فارسی و عربی.
- **پیش‌پردازش هوشمند**: بزرگ‌نمایی متن‌های ریز، معکوس کردن پس‌زمینه‌های تیره و اصلاح کنتراست.
- پشتیبانی از **چند مانیتور** و صفحه‌نمایش‌های با DPI بالا.
- **اجرا در سینی**: اجرای خودکار با ویندوز (اختیاری) و تک‌نمونه (اجرای دوباره‌ی برنامه، همان لحظه انتخاب ناحیه را باز می‌کند).
- **حریم خصوصی**: هیچ اتصال اینترنتی یا ارسال داده‌ای وجود ندارد؛ همه‌چیز روی کامپیوتر خودت انجام می‌شود.
- **یک فایل**: فقط یک فایل پایتون، یا یک `.exe`.

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- پایتون ۳.۹ یا بالاتر (فقط برای اجرا از سورس)
- [Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki) همراه با زبان‌های موردنیاز

## نصب

### ۱. نصب Tesseract
نصب‌کننده‌ی ویندوز را از [صفحه‌ی UB-Mannheim](https://github.com/UB-Mannheim/tesseract/wiki) دانلود کن. موقع نصب در بخش **Additional language data** تیک **Persian** و **Arabic** (و هر زبان دیگری که می‌خواهی) را بزن. مسیر پیش‌فرض `C:\Program Files\Tesseract-OCR` را تغییر نده.

برای اطمینان:

```bat
"C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs
```

### ۲. اجرا از سورس

```bat
git clone <repository-url>
cd snap-ocr
pip install -r requirements.txt
python snap_ocr.pyw
```

### یا استفاده از exe
فایل `SnapOCR.exe` را از بخش [Releases](../../releases) بگیر (یا خودت بساز، پایین توضیح داده شده).

## نحوه‌ی استفاده

1. برنامه را اجرا کن. صفحه بلافاصله تیره می‌شود (از بار بعد برنامه در سینی می‌ماند).
2. روی متن مورد نظر یک مستطیل **بکش**. با `Esc` یا کلیک راست لغو می‌شود.
3. متن خوانده و در کلیپ‌بورد کپی می‌شود.

| کار | روش |
| --- | --- |
| گرفتن متن (حالت پنجره) | `Ctrl+Alt+O` (پیش‌فرض) یا کلیک چپ روی آیکون سینی |
| گرفتن متن (حالت سریع، فقط کپی) | `Ctrl+Alt+Q` (پیش‌فرض) |
| تغییر میانبرها / اجرا با ویندوز | راست‌کلیک روی آیکون سینی ← **تنظیمات** |
| بستن پنجره‌ی نتیجه | `Esc` یا ✕ |
| خروج کامل | راست‌کلیک روی آیکون سینی ← **خروج** |

گزینه‌های خط فرمان: `--background` (اجرای بی‌صدا در سینی؛ اجرای خودکار با ویندوز از همین استفاده می‌کند) و `--make-icon` (ساخت `icon.ico`).

میانبر باید حداقل یک کلید کمکی (`Ctrl`/`Alt`/`Shift`/`Win`) داشته باشد؛ فقط کلیدهای `F1` تا `F24`، `Print Screen`، `Pause` و `Scroll Lock` بدون کلید کمکی مجازند.

## تشخیص خودکار زبان چگونه کار می‌کند؟

۱. یک بار Tesseract با `fas+ara+eng` (هر کدام که نصب باشد) اجرا می‌شود. هم متن و هم میزان اطمینان از همین یک اجرا به دست می‌آید. اگر اطمینان حداقل ۶۰٪ باشد، نتیجه همان‌جا برگردانده می‌شود. این حالت متداول است و معمولاً یکی دو ثانیه بیشتر طول نمی‌کشد.

۲. در غیر این صورت، گزینه‌های بیشتر (خط‌های دیگر و زبان‌های لاتین) هم‌زمان اجرا می‌شوند و نتیجه‌ای که بیشترین اطمینان را دارد انتخاب می‌شود.

نکته‌ها: برای متن‌های اروپایی با حروف خاص، زبان را دستی انتخاب کن تا دقیق‌تر شود. برای دقت بیشتر مدل‌های `tessdata_best` و برای سرعت بیشتر مدل‌های `tessdata_fast` را نصب کن.

## ساخت exe

```bat
build_exe.bat
```

خروجی: `dist\SnapOCR.exe`. فایل exe شامل Tesseract **نیست**. یا Tesseract را روی کامپیوتر مقصد نصب کن، یا نسخه‌ی همراه بساز: پوشه‌ی `Tesseract-OCR` را کنار `SnapOCR.exe` کپی کن و نامش را `tesseract` بگذار.

یک workflow برای GitHub Actions هم در `.github/workflows/build.yml` هست که با push کردن تگی مثل `v1.0.0`، exe را می‌سازد و به Release اضافه می‌کند.

## تنظیمات

تنظیمات (میانبرها، حالت زبان و کپی خودکار) در `%USERPROFILE%\.snap_ocr.json` ذخیره می‌شود. اجرای خودکار از کلید رجیستری `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` استفاده می‌کند.

## عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| «Tesseract پیدا نشد» | آن را نصب کن، یا پوشه‌اش را کنار برنامه بگذار و نامش را `tesseract` کن. |
| زبان نیست / نتیجه خالی است | دستور `tesseract --list-langs` را بزن؛ فایل `.traineddata` را در پوشه‌ی `tessdata` بگذار و برنامه را دوباره اجرا کن. |
| «میانبر ثبت نشد» | برنامه‌ی دیگری آن ترکیب را گرفته است. در تنظیمات ترکیب دیگری انتخاب کن. |
| کندی | فقط زبان‌های لازم را نصب/انتخاب کن و از مدل‌های `tessdata_fast` استفاده کن. |
| متن اشتباه خوانده می‌شود | ناحیه را کمی بزرگ‌تر و با حاشیه انتخاب کن، خطوط را از وسط نبُر و زبان را دستی انتخاب کن. |
